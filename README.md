# MoMoney Maestro v4.2.4 Console

Vercel-native Next.js deployment of the MoMoney Maestro v4.2.4 workbench.

## Deployment contract

- Vercel project: `console`
- Vercel root directory: `apps/console`
- OpenAI credentials are read only from Vercel server environment variables.
- No API key values belong in this repository.
- Prompt compilation, review binding, and release gates fail closed.
- Audio rendering, rights clearance, HPA measurement, and DSP remain external `NOT_RUN` boundaries until actually executed.

The application source lives in `apps/console`.
